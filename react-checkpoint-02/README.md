# React Checkpoint 02 — FIFA Player Cards

Submission for **Front End Development: React JS Fundamentals — React Checkpoint 02**.

## Checkpoint requirements covered

- React project structure compatible with Create React App
- `players.js` containing an array of at least four player objects
- Player attributes:
  - name
  - team
  - nationality
  - jerseyNumber
  - age
  - imageUrl
- `Player.js` reusable React component
- React Bootstrap `Card`
- Props destructuring inside `Player`
- Default props for all player attributes
- Inline styling inside the Player component
- `PlayersList.js`
- Player data imported into `PlayersList`
- Players displayed using `.map()`
- Spread operator used to pass player props
- `PlayersList` imported and rendered in `App.js`
- Responsive styling with Bootstrap and custom CSS
