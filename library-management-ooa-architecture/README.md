# Library Management System (LMS) — Object-Oriented Analysis & Architectural Modeling

Submission for:

**Low level design : Interaction Between System Architecture and Components & Object-Oriented Analysis**

This project focuses on analysis and modeling rather than building a full implementation.

## Deliverables

- Requirement analysis
- Main actors and use cases
- High-level architecture
- Architectural component diagram
- Object-oriented analysis
- Class diagram
- Use case diagram
- Sequence diagrams for:
  - Borrow Book
  - Return Book
- State diagram for the Book object
- Data model
- Functional model
- Behavioral model
- Pseudocode / implementation examples

All diagrams are written in Mermaid so they can be viewed directly on GitHub.
