# Weather App - Network Requests in JavaScript

Checkpoint submission for **System Design : Network Requests in JavaScript**.

## Features
- Search by city
- JavaScript `fetch()` requests
- Geocoding city name to coordinates
- Current temperature, feels-like temperature, humidity, wind, precipitation and weather description
- JSON parsing
- Dynamic DOM updates
- Error handling
- Responsive CSS

## API
This project uses Open-Meteo's Geocoding API and Forecast API. No API key is embedded in the project.

## Files
- `index.html`
- `styles.css`
- `script.js`
- `README.md`

## Run
Open `index.html` in a browser, or use a local server such as:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
