## Flagship Lab Project — BookSphere

[BookSphere](./booksphere) is the final seven-phase lab project: a production-ready
social platform where readers can discover books, publish recommendations, rate
titles, interact with other readers, and receive a personalized feed.

| Phase | Scope | Evidence |
| :---: | --- | --- |
| 1 | Project foundation, React/Vite, Express, MongoDB, core models | [Report](./booksphere/docs/PHASE_1_REPORT.md) |
| 2 | Registration, login, password hashing, JWT cookies, protected routes | [Report](./booksphere/docs/PHASE_2_REPORT.md) |
| 3 | Open Library integration, multi-mode search, recommendation publishing | [Report](./booksphere/docs/PHASE_3_REPORT.md) |
| 4 | Book details, accessible 1–5 rating, averages, distributions | [Report](./booksphere/docs/PHASE_4_REPORT.md) |
| 5 | Likes, comments, sharing, profiles, follows, personalized feed | [Report](./booksphere/docs/PHASE_5_REPORT.md) |
| 6 | Cohesive UI system, responsive layouts, accessibility, usability | [Report](./booksphere/docs/PHASE_6_REPORT.md) |
| 7 | Render architecture, CI gate, production security, deployment verification | [Report](./booksphere/docs/PHASE_7_REPORT.md) |

### BookSphere engineering highlights

- Full-stack same-origin production architecture
- Secure HTTP-only JWT authentication
- Open Library search by title, author, and genre
- Database-backed recommendations, ratings, likes, comments, and follows
- Explainable preference- and interaction-based recommendation scoring
- Responsive design with keyboard, touch, and reduced-motion support
- GitHub Actions CI and declarative Render deployment
- Automated server, build, configuration, routing, health, CORS, and security checks
