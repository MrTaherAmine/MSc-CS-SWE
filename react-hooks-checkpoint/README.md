# React Hooks Checkpoint — MovieVerse

Submission for **Front End Development: React Hooks — React Hooks Checkpoint**.

## Requirements covered

- React project structure compatible with Create React App
- `MovieCard` component
- `MovieList` component
- `Filter` component
- Each movie includes:
  - title
  - description
  - posterURL
  - rating
- User can add a new movie
- User can filter movies by title
- User can filter movies by minimum rating
- React Hooks used with `useState`
- `useMemo` used for the filtered list
- Reusable components and props
- Responsive styling with React Bootstrap and custom CSS

## Components

```text
src/
├── components/
```

## Run locally

```bash
npm install
npm start
```

The application normally opens at:

```text
http://localhost:3000
```
